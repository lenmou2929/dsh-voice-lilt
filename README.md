# dsh-voice-lilt（轻语 Lilt）

`lilt` /lɪlt/ · 说话时声音的起伏；轻声只是它的一档语气。

给 [DeepSeek Harness (DSH)](https://github.com/deepseek-ai) 加一张嘴：**模型自己决定说什么，用你本机的 BreezeTTS2 念出来，音频在 DSH 窗口里自动播放。**

角色扮演时，正文按角色分嗓音、**原文照念**——只听声音也能玩完一轮。

> **非官方插件**。本项目为个人开发，与 DeepSeek、DSH 官方插件、Breeze-TTS-2.cpp 项目均无隶属或背书关系。
> 本仓库**只包含插件代码**：不含任何模型权重、参考音频、角色卡或音色文件。

---

## 它做什么

```
模型 ──speak(text) / 全文念(按标记切正文)──▶ 插件宿主(DSH 主进程)
                                        ├─ 串行队列 + 409 重试 + sha1 缓存
                                        ├─ POST 127.0.0.1:8080/v1/audio/speech（流式）
                                        └─ 同源路由 /voice-breeze/audio/<id>.wav
                                                       │
输入框下方：[● 语音播报 开] [模式：AI 说 ▾] [强度：中] [朗读：全文念] [音色 ▾] [🔊]
会话标题行：[对话] [轨迹] [🎙 语音]   ← 点开是可拖动的操作面板（含播报音量滑块）
（「选项位置」可以切成「悬浮框中」：那时这一排只留开关与重播，其余都进面板）
```

- **内容由模型决定**：它调 `speak` 工具说哪几句，或者（角色扮演）按标记逐段念正文；不朗读整段回复除非你要求。
- **声音由你决定**：界面里选音色、多音色时按 `cast.json` 分角色；模型传的任何 `voice` 参数都不会覆盖你的选择。
- **音频不出本机**：合成走 `127.0.0.1`，播放走 DSH 的同源路由。没有遥测、没有云端调用。

## 前置

1. **DSH**（桌面版或 Web 版均可，需支持插件）。开发时的实测环境是 DSH `0.2.1-rc.2` 及之后的 rc 版本（当前 `0.2.1-rc.5`）。
2. **BreezeTTS2**（本机语音引擎，OpenAI 兼容端点）。没装也行——首次对话时插件会主动问你要不要装。
3. 不需要额外的 npm 依赖：宿主侧只用 Node 内置模块，客户端零依赖。

## 安装

两种方式，任选一种（都在 DSH 的 **插件管理** 里）：

```text
A. 从本仓库装（推荐，以后在插件管理里点更新即可）
   插件管理 → 安装 bundle → 填本仓库的 Git 地址（本页右上角 Code → Clone 里复制）

B. 拿到的是压缩包 / 文件夹
   解压或放到一个固定位置：纯英文路径、不含空格，例如 D:\dsh-voice-lilt
   插件管理 → 安装 bundle → 填本地路径（profile 里会记成 link:D:\dsh-voice-lilt）
   ⚠️ 别放在桌面/下载里随手改名；挪了目录要重新指一次
```

装好后**重启 DSH**（宿主插件只在启动时加载），再刷新页面。

> 装之前建议先装好 **BreezeTTS2**（下一步插件也能帮你装）。插件本身零 npm 依赖，宿主侧只用 Node 内置模块。

## 首次使用：它会把引擎装好

没有 BreezeTTS2 时，`speak` 会返回 `engine-missing`，插件会按固定顺序引导你：

1. 先探你的显卡/显存、内存与各盘空间，给出 2~3 个档位（体积 / 显存 / 代价）；
2. 你挑一个档位；
3. **它必须先问你用途**（个人/研究/非商业 vs 商用）——权重是研究与非商业许可，商用会停下来；
4. **它必须问你装到哪个目录**（不会替你选盘，也不会默认塞 C 盘）；
5. **它还会问你「喜欢男声还是女声」**——装完直接把对应的那把**出厂音色**（`girl` / `boy`）生成好、
   存进引擎的声音库并设为当前音色；
6. 下载 → 校验 → 解压 → 生成启动脚本 → 写配置；
7. 用**你选的那把出厂音色**念一句验收，并告诉你「想换别的嗓子随时说」。

已经有引擎的人不用重装：插件第一次启动时如果配置里定了出厂音色（默认 `girl`），会自己把它补进声音库。

## 四种播报模式

模式是一个下拉框，顺序是 **AI 说 / 摘要 / 全文 / 角色扮演**；**新装插件默认「AI 说」**。

| 模式 | 你听到什么 | 额外调模型 | 强度 |
|---|---|---|---|
| **AI 说**（默认） | 模型把这一轮压成一段口语汇报 | 是，1 次 | 可调 |
| **摘要** | 短回合念首句，长回合念「本轮 N 步 + 首句」 | 否 | 不显示（首句上限固定 240 字） |
| **全文** | 正文**逐字念完**；代码块与表格改念一句提示语；模型自己调 `speak` 会被忽略，只念一遍正文 | 否 | 不可调 |
| **角色扮演** | 全文念（按「旁白：/角色：」切段照念）或 AI 即兴（模型演一遍） | 看朗读方式 | AI 即兴下可调 |

- **强度**：只在「AI 说」和「角色扮演 + AI 即兴」两档出现。
  非角色扮演档：弱 20~40 字 / 中 40~120 字 / 强 120~240 字；
  角色扮演档（决定**段数与篇幅**）：弱 **80~160 字、1 段** / 中 **320~520 字、1~3 段** / 强 **640~900 字、至少 2 段**。
  中、强两档**不设字数上限**；弱档的上限 160 只作规范、插件不会去裁短。段数超过本档上限时，插件会把多出来的段**并进最后一段**（一个字不丢）。
  跟是不是在演剧情无关：查资料、写代码这类正经活也按这个长度用角色口吻说。
  摘要 / 全文 / 角色扮演 + 全文念 三档都不显示它（那几档强度没有作用位）。
  > 改完强度**当轮就生效**：模型每轮开口前会读一次插件给它的档位（`tts_state`），不依赖系统提示词——那边可能还停在这一轮开始时的设置。
- **重播**：两个入口——输入框上方那排里的重播按钮（图标，无文字），以及助手消息动作行末尾的声音图标；都重播最近一轮，
  重启后仍可播（取决于缓存是否还在）。
- **音量**：操作面板「选项」页里一条**常驻**的「播报音量」滑块（0~100，跟面板走、不跟选项位置走）。
  它只调这一侧播放的声音大小——不动系统音量，也不影响合成与缓存；`0%` 是听着静音，播报本身还在跑。

## 角色扮演与多音色

单音色：只用你选的那一把嗓子，`cast.json` 不参与。
多音色：把音色下拉切到「🎭 多音色扮演」，它会变形成**场景选择器**；每局剧本 = `persona.md`（人设）+ `cast.json`（谁用什么嗓子）。

`cast.json` 最小示例（写在 DSH 数据目录的 `voice-breeze/cast.json`）：

```json
{
  "characters": [
    { "name": "旁白",   "voice": "你库里的音色名", "tone": "平静叙述，语速从容" },
    { "name": "角色甲", "voice": "你库里的音色名", "tone": "内敛，声音偏小" },
    { "name": "店主",   "tone": "四十多岁男性，低沉略沙哑，语速慢", "seed": 7 }
  ]
}
```

`voice` 必须是你的声音库里已存在的音色；只写 `tone` + `seed` 则走"设计模式"现场造一把嗓子。
`name` 必须与正文里的标记**逐字一致**。

## 出厂音色与「自己设计一把嗓子」

插件自带两把定稿音色，**开关箱就能用**：

| 名字 | 是什么样的声音 |
|---|---|
| `girl` | 十六七岁少女，清亮偏软、干净，只带一点点害羞和拘谨 |
| `boy` | 二十出头的成年男性，清朗偏沉、干净，语速稳、语气冷静克制，像靠得住的学长 |

它们会**自动进入你的引擎声音库**（插件合成一段 5~10 秒参考音频 → 修好 WAV 头 → 交给引擎入库），
所以在音色下拉里就是两个正常选项，跟别的音色一样选。

想换一把声音，直接跟模型说「我想换一个声音」就行：

1. 它会用**同一句描述 + 不同随机种子**一次生成 3~6 个候选让你报序号（一次调用里听完）；
2. 你挑一个；
3. 它把那一把**自动存进声音库**（名字你定，字母/数字/`-`/`_`），并切成当前音色。

不用你去引擎的 WebUI 点任何东西。挑剩的候选不会留在库里。

## 名字与旧标识：为什么有的地方还写着 `voice-breeze`

插件叫**轻语 Lilt**（包名 `dsh-voice-lilt`），但有三处**故意保留旧标识**，因为改了会让你丢东西：

| 保留的东西 | 在哪 | 改了会怎样 |
|---|---|---|
| 数据目录 `voice-breeze/` | DSH 数据目录下 | 你的设定、角色卡、场景、音量会全部"消失"（其实只是读不到了） |
| HTTP 路由 `/voice-breeze/*` | 插件内部（浏览器同源） | 客户端和宿主全要跟着改，收益为零 |
| 插件实例 id `voice-breeze` | 插件配置里 | 状态键对不上，同样丢设定 |

所以：**看到 `voice-breeze` 不是装错了，那是历史标识。** 你只要认「轻语 Lilt / `dsh-voice-lilt`」这个名字就行。

## 更新与卸载

- **更新**：插件管理里点更新（Git 装的会跟随 `main`）；或者拿到新压缩包后覆盖原目录 → **重启 DSH**。
- **卸载**：插件管理里移除本插件。**数据目录不会自动删**（你的角色卡与设定还在），想清干净再手动删 `voice-breeze/`。

## 配置

配置写在 profile 的插件配置（`cordis.patch.yml` 的 `config`）里，改完重启 DSH。常用的几项：

| 键 | 默认 | 说明 |
|---|---|---|
| `baseUrl` | `http://127.0.0.1:8080` | BreezeTTS 端点 |
| `voice` | 空 | 空 = 用音色描述（设计模式）；填了就用声音库里的音色 |
| `voicePreset` | `girl` | 出厂音色 `girl` / `boy`；插件启动时库里没有就自动生成入库并设为当前音色。界面里手选了别的音色就会清空它 |
| `startScript` | 空 | 引擎没开时用它自动拉起；安装引导会自动写入。自己另外装过引擎的，把它改成你的 `start-server.bat` 路径（不改也能用，只是引擎得你自己先开） |
| `strength` / `fallback` / `multiVoice` / `narrationMode` | 中 / AI 说 / 关 / 全文念 | 界面改一次写一次，运行时不看这四项 |
| `maxChars` | 240 | 单段最长字数（BreezeTTS 单段 60 秒硬上限） |
| `cacheMaxMb` | 512 | 合成缓存上限（LRU） |

运行时偏好落在 DSH 数据目录的 `voice-breeze/state.json`，会覆盖上面这些默认值。

## 排障

| 现象 | 先看 |
|---|---|
| 一句都不响 | 控件上的总开关；DSH 是否重启过（宿主插件只在启动时加载） |
| 提示没装引擎 | 按「首次使用」那段走一遍；`tts_probe` 先探硬件 |
| 角色扮演没分嗓音 | `cast.json` 里的名字与正文标记是否逐字一致；`multiVoice` 是否已开启 |
| 听到的是摘要不是原文 | 「朗读」是否被切到 AI 即兴；模式是否被切到摘要 |
| 点「🎙 语音」没反应 | 刷新页面（客户端改动只需刷新）；面板是否被拖到屏幕外 |
| 启动时报端口占用 | BreezeTTS 单请求串行，别同时跑两次合成；检查 8080 是否被别的进程占了 |

## 隐私与边界

- 文本只在本机流转：插件不向任何远程服务发送内容，只调用 `127.0.0.1` 上的引擎。
- 插件自己的 HTTP 路由（`/voice-breeze/*`）**只放行同源页面请求**，命令行 `curl` 会拿到 403，这是设计如此。
- 不收集使用数据、不做崩溃上报、不写遥测。
- 音频与账目只落在你的 DSH 数据目录，可随时删除。

